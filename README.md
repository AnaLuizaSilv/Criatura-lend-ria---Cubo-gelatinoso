# Criatura lendária-Cubo-gelatinoso
Este repositório armazena a primeira entrega da disciplina de Aprendizado de Máquina, ministrada durante o segundo semestre de 2026 pelo professor Dr. Daniel R. Cassar. Seu principal objetivo é compor uma tarefa introdutória ao Aprendizado de Máquina a partir do modelo KNN (K vizinhos mais próximos).
